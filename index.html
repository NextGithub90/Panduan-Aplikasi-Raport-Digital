Panduan lengkap

Semua menu, dijelaskan dari awal sampai akhir

Gunakan kolom pencarian atau pilih bab pada daftar isi. Checklist tersimpan di browser perangkat ini.

Panduan ini ditujukan untuk pengelola pesantren, Admin, dan Guru yang menggunakan aplikasi Raport Digital. Ikuti urutan pada panduan ini agar data akademik tersusun dengan benar sejak awal sampai raport selesai dicetak.

Catatan: Nama tombol dan menu dalam panduan ini sama dengan yang tampil di aplikasi. Tampilan pada telepon genggam mungkin lebih ringkas; tekan tombol menu di kiri atas untuk membuka navigasi.
1

1. Mengenal akun Admin dan Guru

Aplikasi memiliki dua jenis akun:

Jenis akun Tugas utama
Admin Mengatur profil pesantren, periode akademik, Guru, Santri, mata pelajaran, kelas, KKM, penugasan mengajar, penguncian nilai, pencetakan, akun Admin, dan backup.
Guru Mengisi nilai mata pelajaran yang ditugaskan, nilai ekstrakurikuler jika menjadi pembina, data raport jika menjadi wali kelas, serta mencetak dokumen kelas yang dapat diakses.

Guru hanya dapat melihat kelas dan mata pelajaran yang telah diberikan oleh Admin. Guru tidak dapat membuat kelas, menambah Santri, atau menentukan penugasannya sendiri.

2

2. Masuk ke aplikasi

Login Admin

  1. Buka alamat aplikasi yang diberikan oleh penyedia aplikasi.
  2. Pada halaman Masuk ke Panel, masukkan Username dan Password Admin.
  3. Centang Ingat saya pada perangkat ini hanya jika perangkat tersebut milik pribadi.
  4. Tekan Masuk ke Dashboard.
  5. Jika akun masih memakai password sementara, aplikasi akan langsung meminta penggantian password.

Username dan password Admin pertama diberikan saat aplikasi dipasang. Jika lupa, hubungi penyedia aplikasi atau Admin lain yang masih dapat masuk.

Login Guru

  1. Admin membuat akun Guru terlebih dahulu melalui menu Guru → Data Guru.
  2. Guru membuka alamat aplikasi yang sama dengan Admin.
  3. Guru masuk memakai username dan password sementara yang diberikan Admin.
  4. Pada login pertama, Guru wajib membuat password baru.
  5. Setelah berhasil, Guru akan masuk ke Dashboard Guru.

Jika Guru tidak dapat masuk, Admin perlu memeriksa apakah username benar dan status akun Guru masih Aktif.

3

3. Mengganti password dan keluar

Mengganti password pertama kali

  1. Masukkan Password saat ini.
  2. Masukkan Password baru.
  3. Ulangi password baru dengan tepat.
  4. Tekan Simpan Password.

Password baru minimal 8 karakter dan harus berisi huruf besar, huruf kecil, serta angka.

Mengganti password setelah masuk

  1. Tekan nama pengguna di kanan atas.
  2. Pilih Ganti Password.
  3. Isi password lama dan password baru.
  4. Simpan perubahan.

Keluar dari aplikasi

  1. Tekan nama pengguna di kanan atas.
  2. Pilih Keluar.

Selalu keluar dari aplikasi setelah selesai memakai komputer bersama.

4

4. Urutan penggunaan dari awal sampai akhir

Gunakan urutan berikut saat aplikasi baru mulai dipakai:

  1. Admin login dan mengganti password sementara.
  2. Admin melengkapi Profil Pesantren.
  3. Admin memeriksa pengaturan bahasa Arab pada menu Aplikasi.
  4. Admin membuka Tahun Ajaran dan mengaktifkan semester.
  5. Admin menambahkan Guru, Santri, dan Mata Pelajaran.
  6. Admin menambahkan Ekstrakurikuler beserta Guru pembina.
  7. Admin membuat Kelas, memilih wali kelas, dan memasukkan anggota kelas.
  8. Admin memilih mata pelajaran setiap kelas dan menetapkan KKM.
  9. Admin menentukan Guru Pengampu.
  10. Guru login dan mengisi nilai mata pelajaran.
  11. Guru pembina mengisi nilai ekstrakurikuler.
  12. Wali kelas mengisi presensi, kepribadian, dan catatan raport.
  13. Admin memeriksa kelengkapan pada menu Status Nilai.
  14. Admin mengunci nilai kelas.
  15. Admin atau Guru membuka Cetak Raport, melakukan pratinjau, lalu mengunduh PDF.
  16. Pada akhir tahun, Admin memproses kenaikan kelas atau kelulusan.
  17. Admin membuat dan mengunduh backup secara rutin.

Jangan melompati pengaturan periode, kelas, KKM, atau penugasan Guru. Menu Guru akan kosong jika bagian tersebut belum disiapkan.

5

5. Mengatur profil pesantren

Profil pesantren dipakai pada sampul, biodata, raport, dan dokumen lainnya.

  1. Login sebagai Admin.
  2. Buka menu Profil Pesantren.
  3. Unggah logo pesantren jika diperlukan. Format yang diterima adalah PNG, JPG, atau WebP dengan ukuran maksimal 2 MB.
  4. Lengkapi data berikut:

    5. - Nama pesantren dalam bahasa Indonesia dan Arab. - NSPP. - Alamat, desa/kelurahan, kecamatan, kabupaten/kota, provinsi, dan kode pos. - Nama pimpinan dalam bahasa Indonesia dan Arab. - Nomor telepon, email, dan situs web.

  5. Periksa bagian Pratinjau Identitas Dokumen.
  6. Tekan Simpan Profil.

Jika tombol Isi otomatis atau Terjemahkan tersedia, hasilnya tetap harus diperiksa. Nama orang, nama daerah, dan istilah khusus pesantren dapat memerlukan koreksi manual.

6

6. Mengatur bahasa Arab dan aplikasi

  1. Buka menu Aplikasi.
  2. Pilih penyedia penerjemah yang telah disiapkan pada server.
  3. Aktifkan Terjemahan otomatis hanya jika status menunjukkan kredensial siap.
  4. Atur batas penggunaan karakter sesuai kebutuhan.
  5. Periksa Label Statis Indonesia — Arab satu per satu.
  6. Perbaiki tulisan Arab jika hasil otomatis kurang tepat.
  7. Tekan Simpan Pengaturan.

Jika API penerjemah belum tersedia, aplikasi tetap dapat digunakan. Isi kolom Arab secara manual.

7

7. Membuka tahun ajaran dan semester

  1. Buka Lembaga → Pengaturan.
  2. Tekan Buka Tahun Ajaran Baru.
  3. Masukkan tahun mulai, tanggal mulai, dan tanggal selesai.
  4. Pastikan rentang tanggal sudah benar.
  5. Tekan Buka Tahun Ajaran.

Saat tahun ajaran baru dibuat, Semester Ganjil otomatis menjadi aktif. Data tahun ajaran lama tidak dihapus dan tetap dapat dilihat sebagai riwayat.

Mengaktifkan Semester Genap

  1. Buka Lembaga → Pengaturan.
  2. Cari tahun ajaran yang sedang berjalan.
  3. Pada kolom Semester Genap, tekan Aktifkan.
  4. Setujui konfirmasi.

Semester aktif menjadi acuan untuk kelas, anggota kelas, pengisian nilai, wali kelas, dan pencetakan. Pastikan semester yang tampil di bagian atas aplikasi sudah benar sebelum memasukkan data.

8

8. Mengelola akun Admin dan pengumuman

Menambah Admin lain

  1. Buka menu Admin Aplikasi.
  2. Isi nama lengkap dan username.
  3. Buat password sementara minimal 12 karakter yang berisi huruf dan angka.
  4. Ulangi password.
  5. Pastikan Akun aktif dicentang.
  6. Tekan Tambah Admin.
  7. Berikan username dan password sementara kepada Admin tersebut secara aman.

Admin baru wajib mengganti password pada login pertama. Pada halaman yang sama, Admin dapat memperbarui nama, username, status akun, atau memberikan password sementara baru.

Membuat pengumuman

  1. Buka Dashboard Admin.
  2. Pada bagian Info / Pengumuman, tekan Kelola pengumuman.
  3. Isi judul dan isi pengumuman.
  4. Atur tanggal mulai dan selesai tayang jika diperlukan.
  5. Aktifkan Langsung aktif.
  6. Tekan Tambahkan.

Pengumuman aktif akan terlihat di Dashboard Admin dan Guru.

9

9. Menambah dan mengelola Guru

Menambah satu Guru

  1. Buka Guru → Data Guru.
  2. Tekan Tambah Guru.
  3. Isi nama Indonesia, nama Arab jika ada, username, dan NIP.
  4. Buat password sementara minimal 12 karakter yang berisi huruf dan angka.
  5. Ulangi password sementara.
  6. Lengkapi jenis kelamin, tempat dan tanggal lahir, telepon, email, serta alamat.
  7. Pastikan Akun dan data Guru aktif dicentang.
  8. Tekan Tambah Guru.
  9. Berikan username dan password sementara kepada Guru.

Username setiap Guru harus berbeda. NIP juga tidak boleh sama jika diisi.

Mengubah data atau mereset password Guru

  1. Buka Guru → Data Guru.
  2. Cari nama atau username Guru.
  3. Tekan tombol Edit.
  4. Perbaiki data yang diperlukan.
  5. Untuk mereset password, isi Password sementara baru dan ulangi password. Jika tidak ingin mengganti password, biarkan kolom tersebut kosong.
  6. Tekan Simpan Perubahan.

Setelah password direset, Guru wajib menggantinya ketika login berikutnya.

Menonaktifkan Guru

Edit data Guru lalu matikan pilihan Akun dan data Guru aktif. Guru yang nonaktif tidak dapat login dan tidak dapat dipilih pada penugasan baru.

Lebih aman menonaktifkan Guru yang sudah memiliki riwayat daripada menghapusnya.

Menambah banyak Guru dengan Excel

  1. Buka Guru → Data Guru.
  2. Pada bagian Import Excel, tekan Download Template.
  3. Isi data mulai dari baris 5 tanpa mengubah judul kolom.
  4. Simpan dalam format .xlsx.
  5. Tekan Pilih Excel, pilih berkas, lalu tekan Preview Import.
  6. Periksa jumlah baris valid dan baris bermasalah.
  7. Jika ada kesalahan, perbaiki berkas lalu unggah ulang.
  8. Jika seluruh data valid, tekan Simpan Hasil Import.

Data belum masuk ke aplikasi hanya dengan membuka preview. Penyimpanan baru dilakukan setelah tombol Simpan Hasil Import ditekan.

10

10. Menambah dan mengelola Santri

Menambah satu Santri

  1. Buka Santri → Data Santri.
  2. Tekan Tambah Santri.
  3. Unggah foto jika ada. Format foto adalah JPG, PNG, atau WebP dengan ukuran maksimal 2 MB.
  4. Isi NISN sebanyak 10 digit.
  5. Isi nama, jenis kelamin, tempat lahir, tanggal lahir, dan status.
  6. Lengkapi nama ayah, nama ibu, serta alamat.
  7. Isi versi bahasa Arab jika diperlukan.
  8. Tekan Tambah Santri.

NISN harus unik. Pastikan nama, tanggal lahir, dan data orang tua benar karena data tersebut dipakai pada biodata dan raport.

Mengubah data Santri

  1. Buka Santri → Data Santri.
  2. Cari berdasarkan nama atau NISN.
  3. Tekan Edit.
  4. Perbaiki data atau ganti foto.
  5. Tekan Simpan Perubahan.

Menambah banyak Santri dengan Excel

  1. Buka Santri → Data Santri.
  2. Tekan Download Template pada bagian Import Excel.
  3. Isi data mulai baris 5 tanpa mengubah judul kolom.
  4. Simpan sebagai .xlsx.
  5. Pilih berkas lalu tekan Preview Import.
  6. Perbaiki semua baris yang ditandai bermasalah.
  7. Setelah seluruh baris valid, tekan Simpan Hasil Import.

Import bersifat menyeluruh: jika masih ada baris bermasalah, tidak ada data yang disimpan.

11

11. Mengelola mata pelajaran

  1. Buka Lembaga → Mata Pelajaran.
  2. Periksa mata pelajaran yang sudah tersedia sebelum menambah data baru.
  3. Untuk menambah, tekan Tambah Mata Pelajaran.
  4. Isi kode, nomor urut, nama Indonesia, dan nama Arab.
  5. Pilih kelompok Pondok atau Umum.
  6. Pilih tipe ujian. Jika memilih ujian lisan, tentukan kelompok ujian lisan.
  7. Pastikan status mata pelajaran aktif.
  8. Tekan Tambah Mata Pelajaran.

Nomor urut menentukan susunan mata pelajaran pada daftar dan dokumen. Mata pelajaran kelompok Umum otomatis memakai tipe ujian Tidak berlaku.

Untuk menambah banyak mata pelajaran, gunakan Download Template, isi berkas Excel, buka Preview Import, perbaiki kesalahan, lalu tekan Simpan Hasil Import.

12

12. Mengelola ekstrakurikuler

  1. Buka Raport → Ekstrakurikuler.
  2. Tekan Tambah Ekstrakurikuler.
  3. Isi nama Indonesia dan nama Arab jika ada.
  4. Pilih Guru pembina dari Guru yang aktif.
  5. Isi deskripsi jika diperlukan.
  6. Aktifkan kegiatan.
  7. Tekan Tambah Ekstrakurikuler.

Guru pembina akan melihat kegiatan tersebut pada menu Ekstrakurikuler di akun Guru. Penilaian dapat dilakukan untuk kelas aktif yang dipilih Guru.

13

13. Membuat kelas dan memasukkan anggota

Sebelum membuat kelas, pastikan tahun ajaran, semester, Guru, dan Santri sudah tersedia.

  1. Buka Lembaga → Kelas.
  2. Pilih tahun ajaran dan semester yang benar.
  3. Tekan Tambah Kelas.
  4. Isi nama kelas, misalnya Kelas 1A.
  5. Pilih tingkat 1 sampai 6.
  6. Pilih wali kelas dari Guru aktif.
  7. Pastikan kelas berstatus aktif.
  8. Pada bagian Anggota Kelas, cari lalu centang Santri yang akan dimasukkan.
  9. Tekan Buat Kelas.

Satu Santri hanya dapat menjadi anggota satu kelas aktif pada semester yang sama.

Saat mengedit kelas, anggota aktif tidak dapat dikeluarkan hanya dengan menghapus centang. Gunakan menu Santri → Pindah Kelas agar riwayat akademik tetap tersimpan.

14

14. Mengatur mata pelajaran dan KKM kelas

  1. Buka Raport → Nilai KKM.
  2. Pilih tahun ajaran, semester, dan kelas.
  3. Tekan Tampilkan.
  4. Centang mata pelajaran yang berlaku untuk kelas tersebut.
  5. Isi nilai KKM antara 0 sampai 100 untuk setiap mata pelajaran yang dipilih.
  6. Tekan Simpan Mapel & KKM.

Nilai desimal diperbolehkan, misalnya 72,50. Lakukan langkah ini untuk setiap kelas.

15

15. Menentukan Guru pengampu

  1. Buka Guru → Mengajar.
  2. Pilih tahun ajaran, semester, dan kelas.
  3. Tekan Tampilkan.
  4. Pada setiap mata pelajaran, pilih Guru pengampu.
  5. Tekan Simpan Penugasan.

Setelah penugasan tersimpan, mata pelajaran dan kelas akan muncul di akun Guru terkait.

Jika beberapa kelas memakai susunan yang sama, gunakan Salin Konfigurasi. Fitur ini menyalin mata pelajaran, KKM, dan Guru pengampu dari kelas sumber ke kelas tujuan. Nilai Santri tidak ikut disalin.

16

16. Panduan Guru mengisi nilai

Membuka tugas mengajar

  1. Login menggunakan akun Guru.
  2. Buka menu Pengisian Nilai.
  3. Pilih kelas dan mata pelajaran.
  4. Tekan Isi Nilai.

Jika daftar kosong, Guru perlu meminta Admin memeriksa semester aktif, KKM kelas, status Guru, dan penugasan mengajar.

Mengatur perhitungan nilai

  1. Pada bagian Konfigurasi Perhitungan, isi bobot Harian dan UAS.
  2. Jumlah kedua bobot harus tepat 100%.
  3. Tambahkan nama komponen nilai harian, misalnya NH1, Tugas, atau Praktik.
  4. Minimal ada satu komponen dan maksimal 20 komponen.
  5. Tekan Simpan Konfigurasi.

Mengubah konfigurasi akan menghitung ulang nilai yang sudah tersimpan. Unduh ulang template Excel setelah komponen nilai diubah.

Mengisi nilai secara manual

  1. Masukkan nilai setiap komponen pada rentang 0 sampai 100.
  2. Masukkan nilai UAS pada rentang 0 sampai 100.
  3. Periksa rata-rata, nilai akhir, dan status ketuntasan yang dihitung otomatis.
  4. Tekan Simpan Semua Nilai.

Nilai di bawah KKM akan ditandai. Pastikan seluruh Santri memiliki nilai akhir sebelum kelas dikunci.

Mengisi nilai dengan Excel

  1. Atur dan simpan komponen nilai terlebih dahulu.
  2. Tekan Download Template.
  3. Isi nilai pada berkas tanpa mengubah NISN, nama Santri, atau judul kolom.
  4. Simpan sebagai .xlsx.
  5. Tekan Pilih Excel, lalu Preview Import.
  6. Periksa hasil validasi.
  7. Jika tidak ada kesalahan, tekan Simpan Hasil Import.

Baris tanpa nilai akan diabaikan saat preview. Jika konfigurasi komponen berubah, unduh template baru.

17

17. Panduan Guru pembina ekstrakurikuler

  1. Login sebagai Guru pembina.
  2. Buka menu Ekstrakurikuler.
  3. Pilih kegiatan dan kelas.
  4. Pilih nilai:

    5. - A untuk Santri yang aktif. - B untuk Santri yang kurang aktif. - Kosongkan jika Santri tidak mengikuti kegiatan.

  5. Tekan Simpan Nilai Ekstrakurikuler.

Nilai kosong tidak ditampilkan pada raport. Pengisian massal juga dapat dilakukan melalui Download Template, Preview Import, dan Simpan Hasil Import.

18

18. Panduan Guru wali kelas

  1. Login sebagai Guru yang telah ditetapkan sebagai wali kelas.
  2. Buka menu Wali Kelas.
  3. Isi jumlah Sakit, Izin, dan Alpa untuk setiap Santri.
  4. Pilih nilai Akhlak, Kedisiplinan, dan Kebersihan dari A sampai E.
  5. Isi Catatan Indonesia.
  6. Isi Catatan Arab.
  7. Tekan Simpan Data Wali Kelas.
  8. Tekan Lihat Status Kelas untuk memeriksa progres seluruh Guru.

Catatan Indonesia dan Arab wajib lengkap sebelum Admin dapat mengunci nilai. Setelah kelas dikunci, data hanya dapat dilihat sampai Admin membuka kunci kembali.

19

19. Memeriksa dan mengunci nilai

Penguncian dilakukan oleh Admin setelah seluruh pengisian selesai.

  1. Buka Raport → Status Nilai.
  2. Periksa persentase setiap kelas.
  3. Tekan Detail pada kelas yang akan diperiksa.
  4. Periksa bagian yang belum lengkap.
  5. Minta Guru pengampu atau wali kelas melengkapi data jika masih ada kekurangan.
  6. Jika seluruh data sudah lengkap, tekan Kunci Nilai Kelas.
  7. Setujui konfirmasi.

Kelas hanya dapat dikunci jika:

  • Memiliki Santri aktif.
  • Memiliki mata pelajaran aktif.
  • Setiap mata pelajaran memiliki Guru pengampu.
  • Nilai akhir seluruh Santri sudah tersedia pada setiap mata pelajaran.
  • Wali kelas sudah ditentukan.
  • Presensi seluruh Santri sudah tersimpan.
  • Nilai kepribadian seluruh Santri sudah lengkap.
  • Catatan wali kelas dalam bahasa Indonesia dan Arab sudah lengkap.

Setelah dikunci, Guru tidak dapat mengubah nilai mata pelajaran, nilai ekstrakurikuler, atau data wali kelas. Jika ada kesalahan, Admin dapat membuka halaman detail lalu menekan Buka Kunci Nilai. Setelah koreksi selesai, kunci kembali kelas tersebut.

20

20. Mengatur dan mengunduh hasil raport

Mengatur hasil cetak

  1. Login sebagai Admin.
  2. Buka Raport → Pengaturan Cetak.
  3. Isi tempat cetak.
  4. Isi tanggal cetak tetap atau kosongkan agar sistem memakai tanggal saat dokumen dibuat.
  5. Atur penyesuaian kalender Hijriah antara -3 sampai 3 hari jika diperlukan.
  6. Atur format nama berkas/footer. Placeholder yang tersedia adalah {nama}, {nisn}, {kelas}, {semester}, dan {tahun_ajaran}.
  7. Periksa ukuran kartu Santri. Ukuran baku adalah 85,60 × 53,98 mm.
  8. Tekan Simpan Pengaturan.

Pratinjau dan unduh PDF

  1. Buka menu Cetak Raport.
  2. Pilih semester dan kelas.
  3. Periksa jumlah Santri dan status penguncian.
  4. Pilih Pratinjau untuk memeriksa tampilan di tab baru.
  5. Pilih tombol unduh untuk menyimpan PDF.

Dokumen yang tersedia:

  • Raport per Santri atau satu kelas.
  • Sampul per Santri atau satu kelas.
  • Biodata per Santri atau satu kelas.
  • Kartu Santri per Santri atau satu kelas.
  • Leger Nilai satu kelas.

Raport dan leger final hanya dapat diunduh setelah nilai kelas dikunci. Sampul, biodata, dan kartu dapat diperiksa sebelum nilai dikunci.

Berkas PDF biasanya masuk ke folder unduhan browser. Buka PDF dan periksa nama pesantren, identitas Santri, nilai, tanda tangan, tanggal, serta pemisahan halaman sebelum dicetak.

Mengganti kode QR kartu

Pada daftar dokumen per Santri, Admin dapat memilih Ganti QR. Gunakan hanya jika kode lama perlu dibatalkan karena kartu hilang atau diganti. Setelah kode diperbarui, QR pada kartu lama tidak berlaku.

21. Pindah kelas, kenaikan kelas, dan alumni

Memindahkan Santri pada semester aktif

  1. Buka Santri → Pindah Kelas.
  2. Cari Santri berdasarkan nama, NISN, atau kelas asal.
  3. Tekan Pilih.
  4. Pilih kelas tujuan.
  5. Isi alasan perpindahan minimal 5 karakter.
  6. Tekan Simpan Perpindahan.

Kelas asal, nilai, dan jejak perubahan tetap tersimpan. Nilai kelas yang sudah dikunci tidak dapat dipindahkan.

Melihat riwayat Santri

  1. Buka Santri → Riwayat Santri.
  2. Cari nama atau NISN.
  3. Tekan Lihat.

Halaman ini menampilkan kelas, semester, perpindahan, kenaikan, dan kelulusan tanpa mengubah data lama.

Memproses kenaikan kelas

Kenaikan dilakukan dari Semester Genap yang nilainya sudah dikunci.

  1. Pastikan nilai kelas asal sudah dikunci.
  2. Buka tahun ajaran berikutnya dan aktifkan Semester Ganjil.
  3. Buat kelas tujuan pada tingkat berikutnya.
  4. Buka Santri → Naik Kelas.
  5. Pilih semester asal dan kelas asal.
  6. Pilih kelas tujuan.
  7. Centang Santri yang naik kelas.
  8. Isi catatan proses jika diperlukan.
  9. Tekan Proses Kenaikan dan setujui konfirmasi.

Santri tingkat 1 sampai 5 naik satu tingkat. Proses ini menyimpan riwayat permanen dan tidak boleh dijalankan dua kali untuk data yang sama.

Memproses kelulusan

  1. Pilih kelas tingkat 6 pada menu Naik Kelas.
  2. Pastikan nilai Semester Genap sudah dikunci.
  3. Centang Santri yang dinyatakan lulus.
  4. Isi catatan kelulusan jika diperlukan.
  5. Tekan Proses Kelulusan.

Santri yang lulus otomatis masuk ke menu Santri → Data Alumni.

22. Backup dan pemulihan data

Membuat backup manual

Lakukan backup sebelum perubahan besar, sebelum kenaikan kelas, dan secara rutin.

  1. Buka Backup & Restore.
  2. Tekan Buat & Unduh Backup.
  3. Tunggu sampai berkas ZIP selesai diunduh.
  4. Simpan salinan di tempat lain, misalnya komputer kantor atau penyimpanan awan yang aman.
  5. Periksa riwayat backup dan pastikan statusnya Selesai.

Paket backup berisi data aplikasi, unggahan, dan database.sql untuk pemulihan darurat.

Mengatur backup otomatis

  1. Buka Backup & Restore.
  2. Aktifkan Backup otomatis.
  3. Pilih frekuensi harian atau mingguan.
  4. Pilih hari dan jam.
  5. Atur jumlah backup yang dipertahankan.
  6. Tekan Simpan Pengaturan.

Backup otomatis membutuhkan Cron yang aktif pada hosting. Minta penyedia aplikasi memeriksanya jika backup terjadwal tidak berjalan.

Memulihkan data dari backup

Peringatan: Restore mengganti data aktif dengan isi backup. Jangan melakukan restore hanya untuk mencoba.
  1. Buat dan unduh backup terbaru sebelum memulai.
  2. Pada bagian Restore dari paket backup, pilih berkas ZIP.
  3. Tekan Periksa Berkas.
  4. Periksa tanggal, jumlah tabel, jumlah data, dan status checksum.
  5. Masukkan password Admin saat ini.
  6. Ketik PULIHKAN DATA sesuai petunjuk.
  7. Tekan Buat Pengaman & Mulai Restore.

Gunakan paket backup dari aplikasi yang sama. Jika muncul pesan tentang kunci aplikasi atau paket tidak valid, jangan melanjutkan dan hubungi penyedia aplikasi.

23. Masalah yang sering terjadi

Guru tidak dapat login

  • Pastikan username dan password benar.
  • Pastikan akun Guru berstatus aktif.
  • Jika lupa password, Admin membuka Guru → Data Guru → Edit, lalu membuat password sementara baru.

Menu Pengisian Nilai Guru kosong

  • Pastikan semester yang benar sedang aktif.
  • Pastikan kelas berstatus aktif.
  • Pastikan mata pelajaran dan KKM sudah diterapkan pada kelas.
  • Pastikan Admin sudah menentukan Guru pengampu.

Menu Wali Kelas kosong

Admin harus menetapkan Guru sebagai wali kelas pada Lembaga → Kelas.

Menu Ekstrakurikuler Guru kosong

Admin harus memilih Guru tersebut sebagai pembina pada Raport → Ekstrakurikuler dan memastikan kegiatan berstatus aktif.

Nilai tidak dapat diubah

Periksa apakah kelas sudah dikunci. Jika perlu koreksi, minta Admin membuka kunci melalui Raport → Status Nilai → Detail.

Kelas tidak dapat dikunci

Buka detail pada Status Nilai dan baca daftar data yang belum lengkap. Biasanya penyebabnya adalah nilai salah satu mapel, penugasan Guru, presensi, kepribadian, atau catatan bilingual yang belum lengkap.

Raport atau leger belum dapat diunduh

Raport dan leger final memerlukan nilai kelas yang sudah dikunci. Lengkapi data lalu kunci kelas terlebih dahulu.

Import Excel gagal

  • Gunakan template terbaru dari aplikasi.
  • Gunakan format .xlsx.
  • Isi mulai baris 5.
  • Jangan mengubah nama atau susunan kolom.
  • Periksa pesan kesalahan pada halaman preview.
  • Jika komponen nilai berubah, unduh ulang template nilai.

Tombol terjemahan otomatis tidak berfungsi

Isi kolom Arab secara manual dan minta penyedia aplikasi memeriksa API key, provider aktif, serta batas penggunaan karakter.

Data tidak boleh dihapus

Data yang sudah memiliki riwayat akademik sebaiknya tidak dihapus. Nonaktifkan Guru, mata pelajaran, ekstrakurikuler, atau kelas jika sudah tidak digunakan. Gunakan menu perpindahan, kenaikan, dan kelulusan untuk menjaga riwayat Santri.
